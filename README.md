# Tulas International School Homepage

A responsive React homepage concept for Tulas International School, built with Vite and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Stack and interactions

- React with Vite
- CSS for styling and responsive layouts
- Intersection Observer reveals sections as they enter the viewport
- Lightweight scroll progress indicator
- Responsive mobile navigation and reduced-motion support

Homepage copy is kept free of unverified school statistics. Replace the sample text and external Unsplash photos with approved TIS copy and official assets before publishing. Deploy the generated `dist` folder through Vercel, Netlify, or another static host.
